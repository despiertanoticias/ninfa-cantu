Este es un texto de ejemplo para mostrar cómo se ve una nota completa. Reemplázalo o elimina esta nota desde el panel de administración.

Los párrafos se separan con una línea en blanco. Puedes usar **negritas**, *cursivas*, listas y enlaces.

> Las citas destacadas se ven así, ideales para frases de un discurso o una entrevista.

Cada nota puede tener su propia imagen de portada y una categoría para organizarla.
